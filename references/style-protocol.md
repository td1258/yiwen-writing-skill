# 亿文式知识口播写作协议

## 1. 风格内核

这类文本的价值不在“像某个人说话”，而在于完成一条稳定的认知路径：

> 现实痛点 → 真实经历 → 认知翻转 → 专业解释 → 机制拆解 → 可选工具 → 情绪余味

它同时依赖三种力量：

- **贴身感**：具体生活场景和真实经历让观众进入问题；
- **解释力**：经典、心理学或专业知识把经历从偶然故事变成可理解的机制；
- **行动感**：当选题需要解决问题时，用一个足够小的工具把理解转化成下一步动作。

专业背书和工具都是可选模块。著名人物、经典名句和历史故事属于背书材料，不是每篇必备。素材本身已经能完成解释时，不要为了显得有文化而引用名言；选题只需要被理解时，也不要为了凑结构硬塞方法。

## 2. 四种可轮换结构

不要让连续作品都使用同一开场和同一段落顺序。

### A. 经历主导型

适合用户拥有强烈、真实、有转折的个人经历。

1. 痛点瞬间；
2. 个人经历与错误选择；
3. 转折或自我识别；
4. 专业概念给经历命名；
5. 机制拆解；
6. 必要时给出可用工具；
7. 回扣经历。

### B. 经典主导型

适合原文自身具有强认知落差。

1. 现代人的具体困境；
2. 经典原文；
3. 常见误解与原意边界；
4. 一个主故事；
5. 现代转译；
6. 必要时给出工具或行动原则；
7. 回扣原文。

### C. 冲突案例型

适合职场、关系、商业和教育议题。

1. 一个正在发生的冲突；
2. 双方都自认为正确的理由；
3. 反常识判断；
4. 机制解释；
5. 用户经历或同类短例；
6. 视素材决定是否加入决策工具；
7. 留下选择题。

### D. 工具反推型

适合方法已经成熟、观众急需解决问题的主题。

1. 直接描述卡点；
2. 给出工具名称与适用条件；
3. 用个人经历解释工具如何产生；
4. 引入必要的专业依据；
5. 演示步骤；
6. 说明边界和失败条件；
7. 情绪收束。

## 3. 开头：先制造观看理由

开头必须同时出现“具体困境”和“认知缺口”。优先使用：

- 一种常被误判的行为；
- 一个看似正确、长期却有代价的选择；
- 用户亲历的尴尬、损失或反转；
- 经典名句与现实理解之间的距离。

尖锐命题只是入口，不是结论。正文必须解释它在什么条件下成立。不要用宏大判断掩盖选题空洞。

## 4. 经历：写决定命运的那个瞬间

一段有效经历至少包含四个元素：

1. **场景**：时间、地点、关系或任务；
2. **压力**：当时害怕失去什么；
3. **动作**：具体说了什么、做了什么；
4. **后果**：结果如何迫使“我”改变判断。

重点写选择发生的瞬间，不写流水账。保留能暴露局限、犹豫或自欺的细节；不要把“我”写成事后永远正确的人。

用户没有提供经历时，绝不把通用案例改写成“我曾经”。可以请用户补充，或明确使用“一个常见场景”“我见过的案例”。

### 没有个人经历时，建立主案例

优先级如下：

1. 与主题高度吻合、可核验的著名人物事件；
2. 有出处的历史事件或经典寓言；
3. 公开发表的真实个案；
4. 明确标注为“常见情境”的典型案例。

主案例不是一句例子，而是一条最小叙事链：

> 当时发生了什么 → 人物如何判断 → 做了什么 → 产生什么后果 → 哪个细节揭示核心命题

1—2 分钟稿件中，主案例通常占正文 35%—55%，概念与机制解释通常不超过三分之一。案例讲完后再给概念命名，让观众先看见事情，再听懂理论。

### 从历史案例回落到“那就是我”

著名人物和历史事件提供分量，但天然有距离。案例结束后，用一个日常镜像完成回落：

> 历史事件的因果链 → 一句桥接判断 → 普通人的同构场景 → 具体动作与后果 → 自我识别

日常镜像不是换一个领域随便举例，而是复现主案例里的同一套机制。例如主案例是“害怕损失—抢先自保—集体行动反而放大损失”，日常镜像就应写“害怕被抛弃—抢先质问或冷落—关系真的被推远”。

一个有效的日常镜像至少包含：

1. **瞬间**：几点、哪里、收到什么话或看见什么；
2. **脑内台词**：当事人如何把未知补成最坏答案；
3. **具体动作**：刷新、试探、删除、逃避、攻击或提前放弃；
4. **现实后果**：这个动作如何消耗自己、伤害关系或改变结果；
5. **认出自己**：用一句话点明，刚才的宏大机制正在这个小场景里重演。

用户提供真实经历时，优先用其经历完成回落。没有真实经历时，可以写明确的典型情境，但不得伪装成作者亲历。日常镜像通常占正文约 25%—40%，宁可少解释一个概念，也要把这个瞬间写实。

## 5. 专业背书：用于解释，不用于压人

优先顺序：

1. 原始经典、研究论文或官方资料；
2. 可靠的专业解释；
3. 历史故事或公众案例；
4. 流行说法。

一篇稿通常只保留一个主背书。引用之后必须完成翻译：它与刚才的经历有什么关系，解释了哪一步机制，又不能说明什么。

### 著名人物的使用规则

短稿优先只选一个人物，并根据素材二选一：

- **名句型**：一句原文或忠实转述，加一层关键词拆解；
- **故事型**：一个关键处境、一个选择、一个结果，形成最小故事闭环，不写完整生平。

人物选择需要同时满足：

1. 人物与核心命题有直接关系；
2. 原话、作品或事件有可靠出处；
3. 删除这个人物后，文章的解释力会明显下降；
4. 人物只负责背书或具象化，不替代用户的真实经验。

人物材料加入后，必须落回现代处境。不能讲完古人故事就直接拔高。

如果用户明确指出“没有案例”或当前稿件概念过多，优先改用故事型，不再仅靠名句型修补。

使用经典时分三层写清楚：

- **原文**：作者确实写了什么；
- **语境**：这句话当时在讨论什么；
- **现代转译**：今天借它理解什么问题。

现代转译可以大胆，但不能冒充原意。出处无法确认时不使用引号制造权威感。

## 6. 机制：搭起故事与结论之间的桥

机制解释回答三个问题：

1. 为什么人在当时会这么做？
2. 为什么这个做法短期有效、长期却产生代价？
3. 如果文章需要行动建议，哪个环节可以被改变？

优先使用两到三步因果链，每一步都能从前文材料推出。少用术语；必须用术语时，立刻翻译成普通人的行为表现。

避免把隐喻写成科学事实。例如“被深渊同化”可以作为哲学隐喻，但若写成“必然重塑神经回路”，就需要独立证据。

## 7. 工具：可选，不要硬塞

先判断文章是否需要工具：

- 用户提供了自己的方法、步骤或练习时，整理成工具；
- 选题明确在回答“怎么办”时，可以从机制自然推导工具；
- 选题主要用于看见情绪、理解关系或表达观点时，可以只给一个观察角度，不必设计工具；
- 素材不足时宁愿不写，也不要临时制造一个看似专业的“三步法”。

一个合格工具需要包含：

- **使用时机**：什么时候拿出来；
- **操作步骤**：两至四步；
- **完成标准**：做完能观察到什么；
- **边界**：什么情况下不适用。

工具名称以两到四个字为宜，做到可记忆即可。不要为了起名而起名，也不要把“保持善良、提升认知、勇敢行动”当作工具。

## 8. 情绪余味：停止说理，留下画面

结尾优先使用以下方法之一：

- 回到开头的同一个场景，但人物已经做出不同选择；
- 回扣贯穿全文的一个意象；
- 提出一个有代价的选择，而不是正确答案；
- 用一句克制判断重新定义“强大、清醒、勇气或成功”。

结尾通常只需要一到三段。不要在结论已经成立后连续追加三组排比、祝福和口号。

## 9. 语言与节奏

- 以短句承担判断，以稍长句承担解释；长短交替。
- 每个自然段只推进一个信息点。
- 使用第二人称建立临场感，但不要句句质问观众。
- 可以用“你以为……其实……”完成一次翻转，不要把它变成固定起手式。
- 让例子承担证明，减少“你看、注意、发现没有、真正的”这类路标词。
- 同一个观点解释两次仍未增加信息，就删除后一次。
- 一篇完整稿以一个主故事为中心；其他例子采用短组句，不再展开完整情节。
- 金句来自前文推导，不先写金句再倒推材料。

## 10. 事实与表达边界

交付前逐项检查：

- 第一人称经历是否全部来自用户；
- 引文、章节、年代、人物和数据是否可核验；
- 是否把相关性写成了因果性；
- 是否把一种常见现象写成所有人的共同本质；
- 是否清楚区分原典、现代解释和作者观点；
- 历史人物是否被强行心理分析；
- 著名人物是否真正增加了解释力，而不只是增加权威感；
- 如果加入小工具，它是否真的能执行；如果没有工具，是否符合选题需要；
- 删除任一案例后，文章是否仍然成立；
- 主案例是否具有处境、动作、后果与转折，而不是一句抽象举例；
- 概念解释是否少于案例，并且每一段都在解释案例中的具体细节；
- 历史案例之后是否出现同构的日常镜像，而不是一句泛泛类比；
- 日常镜像是否包含脑内台词、具体动作和现实后果，让观众能够认出自己；

发现风险时，优先改成更准确的表达；不能安全改写时，在“出处与边界”中明确列出，不静默掩盖。

## 11. 完稿标准

达到以下条件才交付：

- 核心命题可以用一句话复述；
- 开头在短时间内给出具体困境和认知缺口；
- 经历有场景、动作和转折，不是虚构的证明材料；
- 专业背书解释了机制，而非装饰观点；
- 机制能够自然推导出结论；需要工具时，工具由机制或用户经验自然产生；
- 如果加入工具，它能够当天执行并验证；
- 结尾回扣全文，没有突然升华；
- 文章没有明显的模板复用痕迹。
